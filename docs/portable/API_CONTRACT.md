# SpAIder Foldable: Core HTTP API contract (v1)

The portable core (`foldable/core`, Python/FastAPI) listens on **loopback only**
(`http://127.0.0.1:<port>`). The port is chosen at start and printed by the core
process as one JSON line on stdout: `{"event":"ready","port":12345}`. The Electron
main process reads it and hands `{baseUrl, token}` to the renderer via preload.

Every request must carry the header `X-SpAIder-Token: <token>` (the token is
generated by the launcher and passed to the core via the environment variable
`SPAIDER_FOLDABLE_TOKEN`). Missing/wrong token → `401 {"detail":"...","code":"unauthorized"}`.
CORS allows only `null`/`file://` origins (packaged Electron renderer) and
`http://localhost:5173` (Vite dev server). Responses are JSON unless stated.

Error shape (all 4xx/5xx): `{"detail": "<German user-facing message>", "code": "<snake_case>"}`
plus optional extra fields named per endpoint.

Identifiers, timestamps: ids are opaque strings (UUID4). Timestamps are ISO-8601 UTC.
Technical identifiers are English; user-facing strings (`*_de`, `detail`) are German.

## Health, setup, system

- `GET /api/health` → `{"status":"ok","version":"0.1.0","app_root":"...","data_dir":"..."}`
- `GET /api/setup/status` → `{"state":"needs_model"|"ready","active_chat_model":ModelInstalled|null,"active_embedding_model":ModelInstalled|null,"runtime_state":RuntimeState}`
  - `RuntimeState`: `"stopped"|"starting"|"ready"|"error"`
- `GET /api/system/info` →
  ```json
  {"os":"windows","arch":"x64","hostname":"...","cpu":"Intel ...","threads":8,
   "ram_total_bytes":0,"ram_available_bytes":0,
   "disk_total_bytes":0,"disk_free_bytes":0,"filesystem":"NTFS","max_file_bytes":null,
   "app_root":"...","data_dir":"...",
   "usage":{"models_bytes":0,"db_bytes":0,"imports_bytes":0,"logs_bytes":0,"downloads_bytes":0},
   "runtime":{"name":"llama.cpp","build":"b12032","variant":"cpu","path":"..."}}
  ```
  `max_file_bytes` is `4294967295` on FAT32 (models larger than that cannot be stored), else `null`.
- `GET /api/system/eject-status` → `{"ready":bool,"active_streams":n,"runtime_processes":n,"db_open":bool,"running_jobs":n,"message_de":"..."}`
- `POST /api/system/shutdown` → `{"ok":true}`. Stops streams, cancels/pauses jobs,
  stops runtime processes, checkpoints and closes the DB, releases the lock, then exits.
- `GET /api/system/logs?tail=200` → `{"lines":["..."]}`

## Settings

`Settings` object (all fields present on GET; PATCH accepts any subset):
```json
{"thinking_enabled":false,"context_tokens":8192,"max_answer_tokens":1024,
 "memory_auto_extract":true,"embedding_enabled":true,"threads":null,
 "temperature":0.7,"system_prompt_extra":""}
```
- `GET /api/settings` → Settings
- `PATCH /api/settings` → Settings (validation error → 422 code `invalid_setting`)

## Models

`ModelCatalogEntry`:
```json
{"id":"qwen3-1.7b-q8_0","name":"Qwen3 1.7B (Q8_0)","role":"chat"|"embedding",
 "family":"Qwen3","publisher":"Qwen","source":"official"|"community",
 "repo":"Qwen/Qwen3-1.7B-GGUF","revision":"<git sha>","repo_url":"https://huggingface.co/...",
 "files":[{"path":"Qwen3-1.7B-Q8_0.gguf","size":1834426016,"sha256":"..."}],
 "total_bytes":1834426016,
 "license":{"id":"apache-2.0","name":"Apache License 2.0","url":"https://..."},
 "architecture":"qwen3","parameters":"1.7B","quantization":"Q8_0","context_length":32768,
 "embedding_dimensions":null,
 "min_ram_bytes":0,"recommended_ram_bytes":0,
 "support":"executed"|"documented",
 "description_de":"...",
 "fit":{"level":"recommended"|"ok"|"tight"|"too_large"|"unknown","message_de":"..."},
 "installed_model_id":null|"..."}
```
`ModelInstalled`:
```json
{"id":"...","name":"...","role":"chat"|"embedding","catalog_id":null|"...","source":"catalog"|"import",
 "path":"<absolute path inside data/models>","size_bytes":0,"sha256":"..."|null,"sha256_verified":bool,
 "architecture":"qwen3","quantization":"Q8_0","context_length":32768,"embedding_dimensions":null,
 "license":{...}|null,"state":"ready"|"broken","active":bool,"created_at":"..."}
```
`Job`:
```json
{"id":"...","kind":"download"|"import"|"activate"|"delete","state":"queued"|"running"|"paused"|"done"|"failed"|"cancelled",
 "catalog_id":null,"model_id":null,"phase":"check_space"|"download"|"verify"|"copy"|"load"|"probe"|"commit"|"cleanup"|"rollback"|null,
 "progress":{"done_bytes":0,"total_bytes":0,"speed_bps":0,"eta_seconds":null},
 "message_de":"...","error":null|{"detail":"...","code":"..."},"result_model_id":null,
 "created_at":"...","updated_at":"...","finished_at":null}
```
- `GET /api/models/catalog` → `{"entries":[ModelCatalogEntry]}` (fit computed against this machine)
- `GET /api/models/installed` → `{"models":[ModelInstalled]}`
- `GET /api/models/active` → `{"chat":ModelInstalled|null,"embedding":ModelInstalled|null,"runtime_state":RuntimeState,"error":null|"..."}`
- `POST /api/models/download` body `{"catalog_id":"..."}` → `202 {"job":Job}`
  - `409 insufficient_space` with `required_bytes`, `free_bytes`
  - `409 already_installed`, `409 job_running`, `409 file_too_large_for_filesystem`
- `POST /api/models/import` body `{"path":"C:\\...\\model.gguf"}` → `202 {"job":Job}`; validation failures end the job with `error.code` in `gguf_invalid|arch_unsupported|role_mismatch|copy_failed`
- `POST /api/models/activate` body `{"model_id":"..."}` → `202 {"job":Job}`; failure never removes the previously active model
- `DELETE /api/models/{id}` → `{"ok":true}`; `409 model_active` if active, `409 job_running` if a job references it
- `GET /api/models/jobs` → `{"jobs":[Job]}`; `GET /api/models/jobs/{id}` → `{"job":Job}`
- `POST /api/models/jobs/{id}/cancel` → `{"job":Job}`; `POST /api/models/jobs/{id}/resume` → `{"job":Job}` (paused/failed downloads continue from the partial file)
- `GET /api/models/jobs/{id}/events` → `text/event-stream`, `event: job` with a Job snapshot on every change, ends after a terminal state.

## Conversations and chat

`Conversation`: `{"id","title","created_at","updated_at","message_count","last_model_id":null|"..."}`
`Message`:
```json
{"id":"...","conversation_id":"...","role":"user"|"assistant","content":"...","created_at":"...",
 "status":"complete"|"streaming"|"stopped"|"error","model_id":null|"...",
 "sources":[Source],"error":null|"...",
 "usage":null|{"prompt_tokens":0,"completion_tokens":0,"time_to_first_token_ms":0,"tokens_per_second":0.0}}
```
`Source` (what the answer was grounded on):
```json
{"kind":"fact"|"document"|"note"|"message","id":"...","label":"...","excerpt":"...",
 "status":"current"|"superseded"|"uncertain","origin":{"kind":"conversation"|"document"|"note","id":"...","title":"...","at":"..."},
 "superseded_by":null|{"id":"...","excerpt":"..."}}
```
- `GET /api/conversations` → `{"conversations":[...]}` newest first
- `POST /api/conversations` body `{"title":null|"..."}` → `201 Conversation`
- `GET /api/conversations/{id}` → `{"conversation":Conversation,"messages":[Message]}` (404 `not_found`)
- `PATCH /api/conversations/{id}` body `{"title":"..."}` → Conversation
- `DELETE /api/conversations/{id}` → `{"ok":true}` (facts extracted from it stay in memory; their origin keeps the title snapshot and is marked deleted)
- `POST /api/conversations/{id}/messages` body `{"content":"..."}` → `text/event-stream`:
  - `event: message` `{"user_message":Message,"assistant_message":Message}` (assistant status `streaming`)
  - `event: status` `{"phase":"retrieving"|"generating"|"memorizing","message_de":"..."}`
  - `event: token` `{"text":"..."}` (append to assistant content)
  - `event: sources` `{"sources":[Source]}`
  - `event: done` `{"message":Message}` (final assistant message, status `complete` or `stopped`)
  - `event: error` `{"detail":"...","code":"..."}` then stream ends; the assistant message is persisted with status `error`
  - Before streaming starts: `409 generation_running`, `409 no_model` (no active chat model), `409 runtime_not_ready`
- `POST /api/conversations/{id}/stop` → `{"ok":true,"stopped":bool}`; the partial answer is kept with status `stopped`
- `GET /api/conversations/{id}/messages/{mid}/sources` → `{"sources":[Source]}`

## Documents

`Document`:
```json
{"id":"...","name":"bericht.pdf","content_type":"application/pdf","size_bytes":0,"text_chars":0,
 "status":"imported"|"indexing"|"indexed"|"failed","warnings":[{"code":"no_text_layer","message_de":"..."}],
 "conversation_id":null|"...","created_at":"...","facts_count":0,"progress":{"done":0,"total":0}}
```
- `GET /api/documents` → `{"documents":[...]}`
- `POST /api/documents` multipart form (`file`, optional `conversation_id`) → `201 Document`. The file is copied into `data/imports/<id>/`. Supported: `.txt .md .markdown .pdf` (text-based). `415 unsupported_type`; `413 file_too_large` (limit 50 MB in V1).
- `GET /api/documents/{id}` → Document; `GET /api/documents/{id}/text?offset=0&limit=5000` → `{"text":"...","total_chars":0}`
- `DELETE /api/documents/{id}` → `{"ok":true}` (removes the copy and the text chunks; extracted facts stay with origin marked deleted)
- `GET /api/documents/{id}/events` → SSE `event: document` snapshots during indexing.

## Memory

- `GET /api/memory/overview` →
  `{"facts":0,"entities":0,"relations":0,"superseded":0,"documents":0,"notes":0,"conversations":0,"messages":0,"index":{"fts":true,"vectors":{"enabled":bool,"model_id":null,"dimensions":null,"count":0}}}`
- `GET /api/memory/search?q=...&limit=20` → `{"results":[Source & {"score":0.0}]}`
- `GET /api/memory/notes` → `{"notes":[Note]}` with `Note = {"id","text","created_at","updated_at"}`
- `POST /api/memory/notes` body `{"text":"..."}` → `201 Note`; `PATCH /api/memory/notes/{id}` → Note; `DELETE /api/memory/notes/{id}` → `{"ok":true}`
- `GET /api/memory/facts?limit=50&offset=0&include_superseded=false` → `{"facts":[Source],"total":0}`

## Electron preload bridge (renderer side)

Exposed as `window.spaider` with `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`:
```ts
interface SpaiderBridge {
  getBackend(): Promise<{ baseUrl: string; token: string }>;   // resolves once the core is ready
  onBackendStatus(cb: (s: {state:"starting"|"ready"|"error"|"stopping"; message?: string}) => void): () => void;
  getAppInfo(): Promise<{ version: string; appRoot: string; dataDir: string; platform: string }>;
  pickModelFile(): Promise<string | null>;        // native open dialog filtered to *.gguf, returns absolute path
  openExternal(url: string): Promise<boolean>;    // only https://huggingface.co/* and https://github.com/ggml-org/llama.cpp* allowed
  requestQuit(): Promise<void>;                   // graceful shutdown then window close
}
```
No other Node/Electron APIs reach the renderer. The renderer never executes content from chat or documents (markdown is rendered without raw HTML; links open only via `openExternal`).
